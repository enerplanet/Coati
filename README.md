# Coati

Coati converts the result files of energy system models to JSON: the netCDF
and HDF5 files that [Calliope](https://www.callio.pe/),
[PyPSA](https://pypsa.org/) and
[AdOpT-NET0](https://adopt-net0.readthedocs.io/) write.

The project is in its beginnings. [CONTRIBUTING.md](CONTRIBUTING.md) tells
how to take part.
