    Options and results¶

    Options¶

    ExtractOptions dataclass ¶

    ExtractOptions(
    labels: bool = True,
    period: str | None = None,
    time_start: str | None = None,
    time_step: str | None = None,
)

    The choices a caller has when a results document is made.

    Attributes:

    • labels (bool) –

      Whether the display name and the colour of a technology are reported, where the file has them.

    • period (str | None) –

      The investment period to report, for a file of AdOpT-NET0 with several; the first if None.

    • time_start (str | None) –

      The first instant of a model whose file records no times, as ISO 8601 text. Together with time_step it makes the timestamps instants instead of positions.

    • time_step (str | None) –

      The distance between two instants, such as 1h or 15min.

    DumpOptions dataclass ¶

    DumpOptions(
    data: bool = True,
    decode: bool = True,
    decode_text: bool = False,
    max_elements: int | None = None,
    variables: tuple[str, ...] = (),
)

    The choices a caller has when a dataset document is made.

    Attributes:

    • data (bool) –

      Whether the values of the variables are part of the document. Without them the document describes the structure of the file.

    • decode (bool) –

      Whether the values are interpreted according to the CF conventions.

    • decode_text (bool) –

      Whether an attribute that holds a JSON or YAML document is reported as that document instead of as text. YAML needs PyYAML.

    • max_elements (int | None) –

      The largest number of elements of a variable whose values are part of the document; None for no limit.

    • variables (tuple[str, ...]) –

      Patterns in the style of the shell, such as /results/flow_*, that select variables by their path or name; every variable if empty.

    JsonOptions dataclass ¶

    JsonOptions(
    indent: int | None = 2,
    non_finite: NonFinite = "null",
    decimals: int | None = None,
    sort_keys: bool = False,
    ensure_ascii: bool = False,
)

    How a document is written.

    Attributes:

    • indent (int | None) –

      Spaces per nesting level, or None for the most compact output without any whitespace.

    • non_finite (NonFinite) –

      What becomes of NaN and the infinities. "null" writes null; "string" writes the strings "NaN", "Infinity" and "-Infinity", which keeps the distinction; "error" refuses the document.

    • decimals (int | None) –

      Decimal places floating-point numbers are rounded to, or None to write every number with the digits needed to read it back unchanged. Rounding also turns negative zero into zero. A number so large that it has no digits at the places in question is written as it is.

    • sort_keys (bool) –

      Write the keys of every object in sorted order instead of the order of the document.

    • ensure_ascii (bool) –

      Escape every character outside ASCII.

    Results dataclass ¶

    Results(
    framework: Framework,
    termination_condition: str,
    success: bool,
    model_name: str | None = None,
    solver: str | None = None,
    objective: float | None = None,
    objective_function_value: float | None = None,
    timestamps: Any = list(),
    weights: ndarray[Any, Any] | None = None,
    periods: list[Any] | None = None,
    capacities: dict[str, float] = dict(),
    storage_capacities: dict[str, float] = dict(),
    generation: dict[str, float] = dict(),
    dispatch: dict[str, ndarray[Any, Any]] = dict(),
    demand_timeseries: ndarray[Any, Any] | None = None,
    demand_by_location: dict[str, float] = dict(),
    unmet_demand_timeseries: ndarray[Any, Any]
    | None = None,
    unmet_demand_by_location: dict[str, float] = dict(),
    transmission_flow: dict[str, Transmission] = dict(),
    costs_by_tech: dict[str, float] = dict(),
    costs_by_location: dict[str, dict[str, float]] = dict(),
    tech_metadata: dict[str, dict[str, str]] = dict(),
    coordinates: dict[str, list[float]] = dict(),
    scenarios: dict[str, float] | None = None,
    details: dict[str, Any] = dict(),
    warnings: list[str] = list(),
)

    What a solved model says.

    Attributes:

    • framework (Framework) –

      The framework that wrote the file.

    • termination_condition (str) –

      How the solver ended, in the words of the framework.

    • success (bool) –

      Whether the model has a solution.

    • model_name (str | None) –

      The name of the model, if the file records one.

    • solver (str | None) –

      The solver, if the file records it.

    • objective (float | None) –

      The cost of the system.

    • objective_function_value (float | None) –

      The value of the objective function, which may include penalties and weights that are no cost.

    • timestamps (Any) –

      The times of the time series: instants, or positions if the file records no times.

    • weights (ndarray[Any, Any] | None) –

      How much each time counts towards a total, for a model in which the times stand for periods of different length or number. The totals of the document are weighted with it, the time series are not.

    • periods (list[Any] | None) –

      The investment period of each time, for a model with several.

    • capacities (dict[str, float]) –

      The capacity of each technology at each location.

    • storage_capacities (dict[str, float]) –

      The capacity of each store to hold energy.

    • generation (dict[str, float]) –

      What each technology puts out over the modelled time, for each location and carrier.

    • dispatch (dict[str, ndarray[Any, Any]]) –

      What each technology puts out at each time, all locations and carriers together.

    • demand_timeseries (ndarray[Any, Any] | None) –

      The demand at each time, all locations together.

    • demand_by_location (dict[str, float]) –

      The demand over the modelled time at each location.

    • unmet_demand_timeseries (ndarray[Any, Any] | None) –

      The demand that is not met at each time.

    • unmet_demand_by_location (dict[str, float]) –

      The demand that is not met, at each location.

    • transmission_flow (dict[str, Transmission]) –

      The exchange between each pair of locations.

    • costs_by_tech (dict[str, float]) –

      The cost of each technology.

    • costs_by_location (dict[str, dict[str, float]]) –

      The cost of each technology at each location.

    • tech_metadata (dict[str, dict[str, str]]) –

      The kind of each technology and what it puts out.

    • coordinates (dict[str, list[float]]) –

      The latitude and longitude of each location.

    • scenarios (dict[str, float] | None) –

      The weight of each scenario, for a stochastic model.

    • details (dict[str, Any]) –

      What else the file says, in the terms of the framework.

    • warnings (list[str]) –

      What a reader of the document should know about its making.

    finish ¶

    finish() -> None

    Derive what follows from the rest: the cost of each technology, and tidy up.

    A technology that puts out nothing at all is dropped from the dispatch, and costs_by_tech lists the technologies that cost something; costs_by_location keeps every entry.

    Transmission dataclass ¶

    Transmission(
    origin: str,
    destination: str,
    timeseries: ndarray[Any, Any],
)

    The exchange between two locations.

    Attributes:

    • origin (str) –

      The location the flow is counted from, the first of the two in the order of their names.

    • destination (str) –

      The other location.

    • timeseries (ndarray[Any, Any]) –

      The net flow that arrives at destination from origin at each time, negative in the opposite direction.
